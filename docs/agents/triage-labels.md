# Triage labels

Peran triage di skill mattpocock dipetakan ke status di [`docs/06-BACKLOG.md`](../06-BACKLOG.md).

| Peran di mattpocock/skills | Status di backlog | Arti |
| --- | --- | --- |
| `needs-triage` | ⬜ + "(triage)" di kolom Fitur | Perlu dinilai pemilik |
| `needs-info` | ⬜ + "(butuh info: ...)" | Menunggu jawaban |
| `ready-for-agent` | ⬜ tanpa catatan | Siap dikerjakan agen |
| `ready-for-human` | ⬜ + "(manual)" | Butuh tindakan manusia (hardware, akun) |
| `wontfix` | ❌ | Dibuang |
